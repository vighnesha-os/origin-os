| Result | Twenty-two loader runs in six boots. **The boot services table:** in every run, the system table named it at `0x98d3ca80`, the same as the loader's copy, byte for byte over its 264 bytes, with `ExitBootServices` at `0x98d26a20` in both and the header's CRC32 `0xb4b91c57` in both. In run 5 the console lost bytes inside that line, and what is left of it says the same. **The memory map** the page tables were built from held no region of an OS-defined type in any run, in 65 to 73 descriptors. In every run the FCH's checks passed (an AMD processor; the DSDT's 256-byte region at `0xfed80300`; the firmware's page tables mapping it to itself). The run found no `BENCH-FCH` and read the board: the FADT's reset register `0xbe` to I/O port `0xb2`; `SMIxC0 0x04000000`, so a write to `0xCF9` raises an SMI; `PMx00 0xe3070bf7, PMx08 0x021c0514, PMx60 0x0800, PMx74 0x1e060117, PMxD2 0x40`, both shutdown bits set. `PMxC0` read `0x00080800` (bit 19, a `0x06` written to `0xCF9`) in eighteen runs, `0x00800800` (bit 23, a shutdown) in runs 3 and 6, and `0x00200800` (bit 21, a sleep state) in runs 12 and 18, each the first run after one of the tool's restarts. **Twenty runs were the control:** the decision line, then a triple fault. In all twenty the firmware's first byte came 5.5 to 5.6 s after that line; the tool calls run 4's undetermined, since its restart was issued 2.9 s after the line. **Runs 3 and 6 made the call,** through the loader's copy, with `X` before it. The firmware's first byte came 5.5 s and 6.1 s after `X`, and no `Y`, no Amendment 2 line and no halting line came in either run. **The firmware's starts:** after thirteen of the fifteen controls that no restart of the tool's disturbed, the firmware opened three times, at 5.5, 28.3 to 28.5 and 51.2 to 51.8 s after the run's last byte. Each opening reached "Pre-memory NB Initialization", and the next run, in the twelve that had one before the deletion, read bit 19. After the other two (runs 2 and 5) it opened once, and the next run read bit 23 and made the call. After each call it opened three times, at the same spacing as after the controls (5.5, 28.3 and 51.7 s; 6.1, 28.9 and 52.1 s). It opened once after Linux's own reboot before run 1, which the FCH recorded as bit 19, and after the tool's restart before run 18, which it recorded as bit 21. The tool's other four restarts landed while the firmware was starting after a triple fault, and are not read for this |
