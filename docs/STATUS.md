| **M2** CPU and memory | done (baseline) | Own GDT/TSS/IDT; exceptions; frame allocator; higher-half kernel with KASLR (ADR-0004) and its own page tables (W^X image from the signed segment table, NX direct map, nothing in the lower half, SMEP/SMAP, guard pages below every stack); kernel heap with `alloc`; CPU feature discovery (x86-64 level graded) and SSE/AVX enabled, with FPU/SIMD state saved and restored across context switches; global kernel pages and TLB shootdowns across CPUs (ADR-0004 H5; PCIDs not yet); x2APIC, a PIT-calibrated timer and I/O APIC interrupt routing (the PIT's IRQ0 routed through it, proven); a monotonic clock (the TSC rate proven against one RTC second; readings consistent across CPUs) and a UTC wall clock from the CMOS RTC; the HPET and the ACPI PM timer discovered and both rate-cross-checked against the TSC; loader memory reclaimed |
| **M3** SMP and scheduler | started | All MADT-enabled CPUs started (1–8 tested); CPU topology from CPUID (SMT/core/package, consistency checked); per-CPU round-robin with preemption, yield, sleep, exit and stack reaping; GS-based CPU-local data; a console that keeps every CPU's lines whole (checked over the whole boot log); a frame-pointer backtrace for panic diagnostics. kernel wait queues with blocking, timed waits and cross-CPU wake-ups by IPI (no lost wake-ups: a producer/consumer transfer and a ping-pong prove it); weighted fair scheduling (stride scheduling, shares within a few per mille of the weights) with a true idle context on every AP; NUMA proximity domains and inter-node distances from the ACPI SRAT and SLIT, with a locality map (CPU/address → node, nearest-node order, the self-nearest invariant), proven at boot across `-smp` 1/2/4/8 (QEMU booted with two `-numa` nodes); a kernel hardware-entropy source (RDSEED/RDRAND with Intel's bounded retry), proven at boot by a batch of draws that are all distinct and non-zero (§59). Not yet: scheduling classes, load balancing, priority inheritance, NUMA-aware allocation/placement (the map is the decision layer; the allocator/scheduler consumers come next), a DRBG over the entropy source |
| **M4** processes and IPC | started | Per-process address spaces sharing the kernel half, with CR3 switched per thread (two processes at the same addresses stay isolated); ring 3 with one DPL-3 gate and `syscall`; user faults end the thread, not the kernel; RSP0 per switch; NMI/#MC on IST; validated, fault-safe copy from user memory (a write system call). Not yet: process objects, handles and capabilities, IPC, loading `.ose` programs |
| **M5** storage | started | PCIe enumeration through the ACPI MCFG: the ECAM window mapped uncached (PAT checked on every CPU), every function listed, every BAR sized and restored; a polled NVMe driver (admin and I/O queues, Identify, read, write, flush; an out-of-range read refused), checked against a GPT test disk xtask builds; both GPT copies validated (CRCs, layout, agreement) and the partitions listed; MSI-X interrupt-driven completions for a thread that blocks on a wait queue; one queue pair and vector per CPU, with all CPUs doing I/O at once; a block layer (a 4 KiB page cache over the namespace, LRU eviction and write-back). A read-only OriginFS v0 on-disk parser and image builder (ADR-0006, **Proposed**): superblock + inode table + direct/single-indirect pointers + linked directory entries, host-tested, **not mounted** (the format decision awaits the owner, §84). A fixed-size bit allocator (lowest-free, model-tested) for the future free-space map and resource ids. Not yet: an IOMMU, a mounted/writable filesystem |
| **M8/M9** groundwork | started | An in-memory VFS (paths, directories, files), used for a live read-only `/sys` tree built from discovered hardware facts; a 2D software rasterizer (fills, blits, alpha blend) cross-checked host↔kernel by CRC; text-engine groundwork (§51): a streaming, error-locating UTF-8 decoder (byte-exact against `core::str`/`from_utf8_lossy` over 20 000 fuzzed inputs), a UTF-16 codec (surrogate pairs, byte-exact against `str::encode_utf16`/`char::decode_utf16`), and a scalar-indexed gap buffer for editable text (50 000-op model test); glob pattern matching for names and paths (oracle/edge-tested); a fixed-capacity ring buffer (input/audio/log queues, 80 000-op model test); DEFLATE (RFC 1951) decompression of all three block types plus the zlib and gzip wrappers (Adler-32 / CRC-32 verified, decompression-bomb guard, validated against zlib vectors); a ustar archive reader and an **initramfs loader that extracts into the VFS at boot** (path-traversal-guarded; §21), boot-proven on an embedded image; and the data-format parsers a config/package/SDK path needs — Base64 (RFC 4648), a depth-limited JSON parser (RFC 8259), semantic-version parsing/precedence with a requirement matcher (§46), a string-keyed FNV-1a hash map for name tables, and a bounded kernel log ring (§69 structured logging). Not wired to syscalls, disk, a framebuffer or an input path yet |
| **M10** connectivity | started | PS/2 scancode decoding (set 1, US layout) and i8042 controller bring-up; the network packet layer (Ethernet/IPv4/ICMP/ARP, the Internet checksum), a TCP connection core (handshake, ordered data, teardown) and UDP, proven by in-memory loopback; a monotonic timer queue; an IPv4 longest-prefix-match routing table (a bit trie, oracle-tested) and a DNS message parser with bounded name decompression (a decompression bomb becomes a clean parse failure); a DHCP client (DISCOVER/REQUEST build, OFFER/ACK/NAK parse, the INIT→SELECTING→REQUESTING→BOUND lease state machine); and the virtio transport (split virtqueue + device negotiation) under a **live virtio-net NIC driver** that brings the device up (capability discovery, feature handshake, DMA ring setup, DRIVER_OK), then takes the OS onto the network: it **ARP-resolves the gateway and obtains a real DHCP lease (10.0.2.15) over the wire** from QEMU's DHCP server — Ethernet/ARP/IPv4/UDP (with checksums)/DHCP all live, TX and RX, proven at boot across `-smp` 1/2/4. Receive is **interrupt-driven**: a receive thread on another processor sleeps on a wait queue for every frame, and only the NIC's MSI-X interrupt (routed to that processor at `cpu::NET_VECTOR`) wakes it — proven at boot by the thread having slept and been woken by the interrupt, with negative controls for a missing wake-up and a masked vector (both leave the thread asleep and fail the boot). Transmit is a proper ring: four descriptors with buffers allocated once, recycled through a free list as the device reports completions (ids validated), batched kicks, and TX-completion interrupts on their own vector that wake a sender waiting for a descriptor — proven by eight frames through the four descriptors with the ring filling and the sender woken by the TX interrupt (controls: no recycling, masked TX vector). **Traffic on the lease:** the OS pings its gateway from its DHCP-leased address (10.0.2.15), unicast to the MAC ARP resolved, and every echo reply matches (identifier, sequence, data, checksums), each received by the interrupt-driven receive thread (control: a corrupted ICMP checksum, which the gateway drops). **A file over the network:** a TFTP reader (RFC 1350, host-tested) fetches the kernel's own initramfs image from QEMU's built-in TFTP server — 4608 bytes in 10 blocks, the last empty — and it is byte-identical to the copy built into the kernel; the receive ring now recycles its buffers (its 8 buffers carried 17 frames), which the transfer needs (controls: a missing file, and no recycling). The fetched file is then unpacked into a fresh VFS and read back by the same checks as the embedded image — the first filesystem content taken from the network (control: one downloaded byte corrupted). Every awaited reply has a 2 s timeout: a lost reply fails its own step with a named reason (`timed out after 2000 ms waiting for …`) and the rest of the datapath carries on. The TFTP reader retransmits on a timeout: the boot drops its first read request on purpose (a corrupted checksum the server discards), and the file still arrives identical after one retransmission (control: no retransmission). The DHCP exchange retransmits too: the boot drops its first DISCOVER on purpose, and the lease is still bound after one retransmission (control: no retransmission → no lease). No live keystrokes (await the keyboard IRQ), or a socket API / routing beyond the gateway yet |
