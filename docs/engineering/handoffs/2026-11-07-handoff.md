## 2. Owner decisions in force (ADR-0001)

- **D1** `.ose` uses native ONBF segments. ELF64 is linker output only; `onbf-pack` converts it.
- **D2** Third-party drivers run in user mode only. Kernel-mode drivers are first-party only.
- **D3** Signatures are Ed25519 + ML-DSA-65; roots, kernel and release keys use Ed25519 + ML-DSA-87. Both must verify. The OS contains verification code only.
- **D4** Publishing is open, in tiers: Verified / Notarized / Unverified.
- **D5** 64-bit only. No `.exe`/`.msi`, no 32-bit, no x32.
- All 12 defaults in ONBF Appendix B are approved.

**Still open, owner decision needed:** the boot trust anchor (signing under Microsoft UEFI CA 2023, or Origin keys enrolled in firmware). Write it as a *Proposed* boot ADR. It cannot become Accepted without the owner (CLAUDE.md §84 exception).
